# Arduino — конспект занятия № 1

**Тема:** Основы Arduino, устройство микроконтроллера и принцип работы программы.

## 1. Что такое Arduino?

**Arduino** — это платформа для создания электронных устройств, которая включает в себя аппаратную часть (плату) и программную среду для разработки.

С помощью Arduino можно создавать:

- Роботов и автоматизированные устройства.
- Системы управления освещением.
- Метеостанции и устройства с датчиками.
- Системы автоматического полива.
- Устройства с дисплеями, кнопками, моторами и светодиодами.

Основная идея работы Arduino:

1. Получить данные от датчиков или других устройств.
2. Обработать полученные данные согласно программе.
3. Выполнить действие с помощью подключённых компонентов.

**Пример:** датчик измеряет температуру, микроконтроллер обрабатывает показания и включает вентилятор, если температура превышает заданное значение.

## 2. Что такое микроконтроллер?

**Микроконтроллер** — это небольшая вычислительная система, предназначенная для управления электронными устройствами.

В отличие от обычного компьютера, микроконтроллер обычно выполняет специализированные задачи и взаимодействует с внешними компонентами через свои входы, выходы и интерфейсы связи.

В Arduino UNO R3 используется микроконтроллер **ATmega328P**.

### Основные компоненты микроконтроллера

| Компонент | Назначение |
|---|---|
| CPU | Выполняет инструкции программы |
| Flash | Хранит загруженную программу |
| RAM | Хранит временные данные во время выполнения программы |
| EEPROM | Позволяет сохранять небольшие объёмы данных после отключения питания |
| Периферия | Обеспечивает работу таймеров, входов, выходов и интерфейсов связи |

### Как это понять?

Микроконтроллер можно представить как небольшого исполнителя:

- **Flash** — место, где хранится программа.
- **RAM** — рабочее пространство для временных данных.
- **CPU** — выполняет инструкции.
- **Периферия** — инструменты для взаимодействия с внешним миром.

У микроконтроллера значительно меньше вычислительных ресурсов, чем у обычного компьютера, поэтому программы для него обычно разрабатываются с учётом ограничений памяти и производительности.

## 3. Из чего состоит Arduino UNO R3?

Arduino UNO R3 — это плата, на которой установлен микроконтроллер и расположены элементы, необходимые для подключения питания, компьютера и внешних устройств.

Основные элементы платы:

| Элемент | Назначение |
|---|---|
| ATmega328P | Выполняет программу |
| USB-разъём | Подключение к компьютеру, загрузка прошивки и обмен данными |
| Цифровые пины | Чтение и выдача цифровых сигналов |
| Аналоговые входы | Измерение аналогового напряжения |
| Пины питания | Подача питания на совместимые внешние компоненты |
| Светодиод L | Встроенный светодиод, обычно подключённый к цифровому пину 13 |
| Кнопка Reset | Перезапуск микроконтроллера |

На плате также расположены индикаторы:

- **ON** — показывает наличие питания.
- **TX** — индикатор передачи данных.
- **RX** — индикатор приёма данных.

## 4. Что такое пины Arduino?

**Пины** — это контакты, через которые микроконтроллер взаимодействует с внешними электронными компонентами.

Например, к ним можно подключить светодиод, кнопку, датчик или управляющий вход драйвера мотора.

Основные категории пинов Arduino UNO R3:

- **Digital** — цифровые входы и выходы.
- **Analog** — аналоговые входы.
- **Power** — контакты питания и земли.
- **Communication** — контакты, используемые интерфейсами связи, например UART, SPI и I²C.

Некоторые пины могут выполнять несколько функций в зависимости от того, как они используются в программе.

## 5. Цифровые и аналоговые сигналы

### Цифровой сигнал

Цифровой сигнал в простейшем случае имеет два логических состояния:

- `HIGH` — высокий логический уровень.
- `LOW` — низкий логический уровень.

Например, цифровой выход может управлять светодиодом, включая и выключая его.

Для работы с цифровыми пинами используются функции:

```cpp
pinMode(13, OUTPUT);
digitalWrite(13, HIGH);
digitalWrite(13, LOW);
```

- `pinMode()` задаёт режим работы пина.
- `digitalWrite()` устанавливает цифровой уровень на выходе.

### Аналоговый сигнал

Аналоговое напряжение может изменяться в определённом диапазоне.

Например, потенциометр позволяет изменять напряжение поворотом ручки. Arduino UNO R3 может измерять такое напряжение с помощью аналогового входа.

Для чтения аналогового значения используется:

```cpp
int value = analogRead(A0);
```

На стандартном Arduino UNO R3 при настройке по умолчанию результат `analogRead()` находится в диапазоне от `0` до `1023`.

**Важно:** функция `analogRead()` измеряет напряжение на аналоговом входе, а не определяет физическую величину напрямую. Для получения температуры, расстояния или другой величины необходимо учитывать характеристики подключённого датчика.

## 6. Как устроена программа Arduino?

Программы Arduino обычно пишутся на языке C++ с использованием Arduino Core — набора функций и библиотек, упрощающих работу с оборудованием.

В типичной программе есть две основные функции:

```cpp
void setup() {
    // Выполняется один раз при запуске
}

void loop() {
    // Повторяется снова и снова
}
```

### Функция `setup()`

Выполняется один раз при запуске микроконтроллера или после его перезапуска.

Обычно здесь:

- Настраивают режимы пинов.
- Запускают последовательную связь.
- Инициализируют датчики и другие компоненты.

### Функция `loop()`

Выполняется циклически, пока микроконтроллер работает.

Здесь обычно:

- Считывают показания датчиков.
- Проверяют состояние кнопок.
- Выполняют логику программы.
- Управляют светодиодами, моторами и другими устройствами.

### Пример: мигание встроенного светодиода

```cpp
#include <Arduino.h>

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);

    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}
```

Разбор программы:

1. `#include <Arduino.h>` подключает объявления основных функций Arduino.
2. `pinMode(LED_BUILTIN, OUTPUT)` настраивает пин встроенного светодиода как выход.
3. `digitalWrite(LED_BUILTIN, HIGH)` включает светодиод.
4. `delay(1000)` приостанавливает выполнение программы примерно на одну секунду.
5. `digitalWrite(LED_BUILTIN, LOW)` выключает светодиод.
6. После завершения `loop()` запускается снова, поэтому светодиод продолжает мигать.

`LED_BUILTIN` — предопределённая константа, обозначающая встроенный светодиод на используемой плате.

## 7. Что такое прошивка?

**Прошивка** — это программа, загруженная в память микроконтроллера и предназначенная для управления его работой.

Обычно процесс разработки проходит следующие этапы:

1. Написание исходного кода.
2. Компиляция исходного кода в машинный код.
3. Загрузка полученной программы в память микроконтроллера.
4. Запуск программы на плате.

После загрузки прошивки Arduino может работать самостоятельно, без постоянного подключения к компьютеру.

Компьютер нужен для разработки, загрузки программы и, при необходимости, обмена данными с платой.

## 8. Среда разработки и PlatformIO

Для разработки можно использовать Arduino IDE или Visual Studio Code с расширением PlatformIO.

PlatformIO позволяет управлять проектом, компилировать программу, загружать прошивку и подключать библиотеки.

Типичная структура проекта PlatformIO:

```text
project/
├── .pio/
├── .vscode/
├── include/
├── lib/
├── src/
│   └── main.cpp
├── test/
└── platformio.ini
```

Назначение основных элементов:

| Элемент | Назначение |
|---|---|
| `.pio/` | Результаты сборки и служебные файлы PlatformIO |
| `.vscode/` | Настройки Visual Studio Code |
| `include/` | Заголовочные файлы проекта |
| `lib/` | Библиотеки проекта |
| `src/` | Исходный код программы |
| `test/` | Тесты проекта |
| `platformio.ini` | Конфигурация проекта |

Пример конфигурации для Arduino UNO R3:

```ini
[env:uno]
platform = atmelavr
board = uno
framework = arduino
```

Здесь:

- `env:uno` — название окружения PlatformIO.
- `platform = atmelavr` — платформа для микроконтроллеров AVR.
- `board = uno` — целевая плата Arduino UNO.
- `framework = arduino` — используемый фреймворк Arduino.

### Основные задачи PlatformIO

- **Build** — компилирует программу и проверяет, удалось ли её собрать.
- **Upload** — загружает собранную прошивку в плату.
- **Clean** — удаляет результаты предыдущей сборки, чтобы при необходимости выполнить сборку заново.

`Clean` не стирает прошивку из памяти Arduino. Отключение USB также не удаляет загруженную программу.

## 9. Последовательная связь (Serial)

Последовательная связь позволяет Arduino обмениваться данными с компьютером или другими устройствами.

В Arduino UNO R3 обмен данными с компьютером обычно организован через USB и последовательный интерфейс микроконтроллера.

Например, Arduino может отправить компьютеру сообщение о температуре, а компьютер — передать команду включения светодиода.

### Инициализация связи

```cpp
Serial.begin(9600);
```

Эта команда запускает последовательный интерфейс со скоростью `9600` бод.

Компьютер и Arduino должны использовать совместимые настройки связи. Для обычного Serial Monitor и простого обмена с Python обычно выбирают одинаковую скорость на обеих сторонах.

### Отправка сообщения

```cpp
Serial.println("Hello!");
```

Отправляет текст `Hello!` и добавляет перевод строки.

### Проверка наличия данных

```cpp
if (Serial.available() > 0) {
    char symbol = Serial.read();
}
```

- `Serial.available()` сообщает, сколько байтов доступно для чтения.
- `Serial.read()` читает один байт из входного буфера.

Программа может читать поступающие байты, собирать из них строку и выполнять действие после получения специального символа, например `\n`.

### Что такое COM-порт?

В Windows последовательное устройство обычно отображается как COM-порт, например `COM5`.

Номер порта может меняться при переподключении устройства или изменении настроек системы.

**Serial Monitor** — инструмент, с помощью которого можно отправлять текстовые команды Arduino и смотреть ответы платы.

## 10. Как Python взаимодействует с Arduino?

Arduino UNO R3 не запускает обычные Python-программы непосредственно на ATmega328P. Но Python может работать на компьютере и обмениваться данными с платой через USB.

Для последовательной связи из Python можно использовать библиотеку `pyserial`.

Установка:

```bash
python -m pip install pyserial
```

Пример отправки команды:

```python
import serial
import time

with serial.Serial("COM5", 9600, timeout=2) as arduino:
    time.sleep(2)

    arduino.write(b"PING\n")

    response = arduino.readline().decode("utf-8").strip()
    print(response)
```

В этом примере:

1. Python открывает последовательный порт `COM5`.
2. Использует скорость `9600` бод.
3. Отправляет байты `PING\n`.
4. Читает строку ответа от Arduino.
5. Выводит полученное сообщение.

Этот пример предполагает, что прошивка Arduino умеет принимать команду `PING` и отправлять ответ. Если используется другой номер COM-порта, его необходимо заменить.

При открытии порта Arduino UNO R3 может перезапуститься. Поэтому в примере предусмотрена небольшая пауза перед отправкой команды.

Таким образом, можно разделить задачи:

- **Arduino** взаимодействует с датчиками и исполнительными устройствами в реальном времени.
- **Python** выполняет более сложную обработку данных, ведёт журналы, предоставляет интерфейс пользователя или управляет логикой на компьютере.

## 11. Общая схема работы электронного устройства

Многие проекты на Arduino можно представить в виде следующей последовательности:

```text
Датчик
   ↓
Получение данных
   ↓
Микроконтроллер
   ↓
Обработка данных по программе
   ↓
Управляющий сигнал
   ↓
Исполнительное устройство
```

Например:

1. Датчик измеряет расстояние.
2. Arduino получает показания.
3. Программа сравнивает расстояние с заданным порогом.
4. Если препятствие близко, Arduino подаёт управляющий сигнал.
5. Драйвер управляет мотором или другим исполнительным устройством.

Если в проекте участвует компьютер, схема может быть дополнена обменом данными через USB.

## 12. Частые ошибки начинающих

- Редактирование файла в другой папке проекта.
- Запуск сборки не из того проекта PlatformIO.
- Выбор неправильного COM-порта.
- Разные скорости передачи данных у Arduino и Serial Monitor.
- Отправка команды без ожидаемого символа завершения строки.
- Подключение компонентов к неподходящему напряжению.
- Подключение мотора непосредственно к пину Arduino без подходящего драйвера.
- Ожидание, что `Clean` удалит прошивку с платы.
- Ожидание, что Arduino UNO R3 будет запускать обычный Python-код непосредственно на микроконтроллере.
